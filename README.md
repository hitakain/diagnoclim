# diagnoclim

Application Flutter de recherche de codes defaut climatisation (`lib/`, `codes.json`).

## ebay_agent/

Agent local-first "photo -> vente eBay" : identification automatique d'un
objet photographie, recherche de prix, redaction et publication automatique
d'une annonce eBay, puis surveillance et ajustement du prix jusqu'a la vente.
Voir [ebay_agent/README.md](ebay_agent/README.md).
